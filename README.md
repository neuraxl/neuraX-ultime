# NEURAX–ULTIME (NXU$)

**Plateforme cognitive évolutive** — unifier les connaissances, les agents intelligents, les workflows, les simulations et les infrastructures technologiques au sein d'un seul organisme numérique.

> L'écosystème numérique actuel est fragmenté : données en silos, outils qui ne communiquent pas, décisions sans vision globale. NXU rompt avec ce paradigme.

🚀 **Démo en ligne :** https://nexus-astra-nova--savardrjr.replit.app/idl

## L'architecture — 5 piliers

```
ORIGIN → CONTINUUM → PRIME → NEXUS → NXU CORE → LEVIATHAN
```

| Pilier | Rôle |
|--------|------|
| **Leviathan** | Socle opérationnel : infrastructure distribuée, sécurité, orchestration |
| **NXU Core** | Cerveau cognitif : connaissances, mémoire, agents, workflows, simulations |
| **NEXUS** | Système nerveux : communication et cohérence entre tous les modules |
| **PRIME** | Usine à paradigmes : génération de cadres conceptuels |
| **CONTINUUM** | Moteur d'évolution : cycles de mise à jour et d'adaptation |

## La formule cognitive

```
Données → Information → Connaissance → Compréhension → Sagesse
↳ Décision → Action → Évolution → Émergence → Nouvelle Connaissance
```

## Installation

```bash
npm install
# Créer un fichier .env avec : OPENAI_API_KEY=votre_clé
# (ne JAMAIS commiter le .env — voir .gitignore)
npm start
```

Le serveur écoute sur `http://localhost:3000`.
